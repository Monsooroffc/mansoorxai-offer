# @mansoorxai | Instagram auto-reply setup

A static service landing page for small businesses that want help setting up Instagram auto-replies for common DMs and keyword comments.

**Live website:** https://monsooroffc.github.io/mansoorxai-offer/

## About the project

The page explains the setup offer, outlines the first steps, and directs enquiries to WhatsApp. The focus is one useful reply flow, with wording and scope agreed before setup.

This repository contains the landing page only. It does not contain an Instagram bot, an automation backend, or a custom AI platform. Reply flows depend on the business's account and the tools chosen.

## Website features

- Responsive layout for mobile and desktop.
- Service overview and a short setup process.
- WhatsApp enquiry buttons.
- Inline styles and an embedded illustration.
- No external dependencies, font downloads, or JavaScript.

## View locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No package installation or build step is required.

## Edit the page

All website content and styling are in `index.html`.

- Update the HTML to change headings, service details, or other copy.
- Update the inline CSS to change colours, spacing, or layout.
- Keep all contact buttons pointed to the intended WhatsApp number.
- Open the file in a browser and check both mobile and desktop layouts before publishing.

## Hosting

The website is hosted on GitHub Pages from the `main` branch and repository root.

To update the live page, commit changes to `index.html` on `main` and allow the Pages deployment to finish. Check the live website after deployment.

To host a separate copy, keep `index.html` at the repository root and configure GitHub Pages to publish from that branch and root folder.
